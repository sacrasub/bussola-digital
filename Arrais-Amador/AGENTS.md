# Diretrizes do Projeto: Simulado Arrais - Bússola Digital
- **Stack**: React (TypeScript), Tailwind CSS, Lucide Icons, Vite, Vite PWA.
- **Arquitetura**: SPA 100% Client-Side. Dados lidos via JSON estático em /public/data.
- **Persistência**: LocalStorage (histórico de simulados, caderno de erros, progresso, flashcards).
- **Identidade Visual**: Tema náutico moderno (Azul Marinho `#0B192C`, Dourado `#E0A96D`, Branco `#F8FAFC`, Esmeralda `#10B981`, Rubi `#EF4444`).
- **Performance**: Mobile-first, acessível, suporte a PWA (offline-first com Web Audio API para apitos náuticos).
- **Rigor Normativo**: Baseado na LESTA (Lei 9.537/97), RLESTA (Dec. 2.596/98), NORMAM-211/DPC Atualizada 2026, RIPEAM-72 e Manual IALA Região B.
